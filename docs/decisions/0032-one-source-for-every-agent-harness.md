# 0032 — One source of agent instructions for every harness, under Codex's cap

Date: 2026-10-27
Status: accepted

## Context

The product owner's colleagues will work on Backchannel with Codex and opencode as well as Claude Code (#233). On 2026-10-27, at `b20793e`:
- **Codex started at the root loaded nothing of this repository's instructions** [measured on #233]. Codex reads every `AGENTS.md` from the git root down to where it starts, leaves `@path` imports as text, and cuts the concatenation at 32 KiB, silently.
- **opencode sends the root `CLAUDE.md`** while no root `AGENTS.md` exists, and the root `AGENTS.md` in its place once one does.
- **Claude Code does not read a root `AGENTS.md`** unless `CLAUDE.md` imports it.
- **What Claude Code always loaded was about 44 KB**: `CLAUDE.md`, 26.8 KB of it the guide inherited from Conversationaly, plus the two rules not scoped to paths. That is about 11.6 KB over Codex's cap.

The product owner decided on 2026-10-27 (#233):
- `.claude/` stays the one source, and what other harnesses read is generated from it as copies, because colleagues work on Windows;
- the inherited guide moves out of the always-loaded instructions;
- a byte-budget test holds the cap.

## Decision

1. **`CLAUDE.md` keeps only its "Backchannel — read this first" section.** The inherited guide moves unchanged to `docs/codebase-guide.md`, and that section names it, to be read before working on the audio, transcription and storage layers.
2. **The root `AGENTS.md` is generated by `scripts/gen-agent-files.mjs`.** It holds that section and `.claude/rules/workflow.md` and `testing.md` embedded whole, and ends with `<!-- END:backchannel-agents-md -->`. `CLAUDE.md` does not import it, so Claude Code loads each rule once, and Codex and opencode read the same text.
3. **The rules scoped to paths are not embedded.** They reach Codex through an index (#251).
4. **Nothing is generated under `frontend/`.** Its `AGENTS.md` and `CLAUDE.md` belong to Next.js.
5. **Every chain of `AGENTS.md` files stays under 32 768 bytes,** less one byte a line for a CRLF checkout (`agents-md-fits-codex.test.mjs`). On 2026-10-27, the root's 18 956 bytes and `frontend/`'s 678 came to 19 634.
6. **A tracked file's backticked `.claude/…` path must resolve** (`every-claude-path-resolves.test.mjs`).

## Consequences

- **A session no longer starts with the inherited guide in context.** An agent working on audio, transcription or storage has to open it; the "read this first" section says so.
- **An edit to `CLAUDE.md`'s section or to an unscoped rule needs `node scripts/gen-agent-files.mjs`** afterwards. The drift test fails until it is run.
- **Growing an always-loaded rule has a ceiling.** Past the budget, something moves out, as the guide did.
