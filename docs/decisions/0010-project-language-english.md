# ADR 0010: The project language is English

Date: 2026-09-01
Status: accepted

## Context

This is an open-source project. Design discussions between the maintainers happen in Russian, but everything
that lives in the repository or faces contributors must be readable by anyone.

## Decision

- All repository artifacts are written in English: code and comments, commit messages, documentation, ADRs,
  issues, pull requests, release notes, and UI strings by default.
- ADRs 0001–0009 were first written in Russian and rewritten in English on the same day.
- Russian appears only where it is the subject matter (for example, STT models for Russian) or in user-facing
  localization once that is added.
