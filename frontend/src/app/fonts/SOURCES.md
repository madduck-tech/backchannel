# IBM Plex: where these files come from

IBM's own files, unmodified (#264). The licence reserves the font name "Plex": a subset or a converted copy may not use it, so these are IBM's `complete/woff2` files, not Google's subsets. `frontend/tests/lib/fonts-ship-in-the-repository.test.mjs` holds every file to the sha256 below. `frontend/public/IBM-Plex-LICENSE.txt` is a byte-identical copy of the licence, so that the built app carries it.

IBM tags each package on its own: Sans comes from `@ibm/plex-sans@1.1.0`, Serif from `@ibm/plex-serif@2.0.0`, and Mono and the licence from `@ibm/plex-mono@2.5.0`.
