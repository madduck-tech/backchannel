# CLAUDE.md

## Backchannel — read this first

This repository is **Backchannel**, an open-source realtime meeting-copilot platform, built as a
hard fork of Conversationaly (ADR 0001). Product direction, scope and rules live in:

- `docs/development-workflow.md` — the five cycles, approval gates, definition of done. Normative.
- `docs/decisions/README.md` — every accepted decision (ADRs). Read the index every session.
- `design/backchannel/DESIGN.md` — the design system; `tokens.css` next to it for prototypes.
- `.claude/rules/` — the hard rules. `workflow.md` and `testing.md` apply to every change and are always
  loaded. The others are scoped to paths: Claude Code loads one when a matching file is read, and
  `AGENTS.md` indexes them for Codex and opencode, which must open the rule themselves.
- `docs/codebase-guide.md` — the guide inherited from Conversationaly: build and run commands, the audio
  pipeline, live transcription, the Tauri command and event pattern, the sidecar's one-model rule and
  platform notes. Read it before building, or before working on audio, transcription, storage or the
  summary sidecar.
- `AGENTS.md` — the same instructions for Codex and opencode, generated by `scripts/gen-agent-files.mjs`
  from this section and the two unscoped rules. Edit the sources, never it.

Agent commits end with a `Co-Authored-By:` trailer naming the model that wrote them, plus the session
link when available.

**No text injection into other applications without a verified caret anchor.** No injection code exists today. This is a rule for whoever builds it, not a description of current behavior.

- Never write a whole field. FluidVoice, the macOS dictation app studied for this, has Accessibility rungs that replace the target's entire `kAXValue`, and the target is sometimes picked by a hierarchy walk rather than by focus. The field it destroys need not be the one the user is typing in.
- Those destructive rungs are reached precisely when `kAXValue` / `kAXSelectedTextRange` are unreadable: Electron apps, web views, terminals. For a desktop dictation tool that is the majority case, not the tail.
- One occurrence is unbounded loss of someone else's document, and we leave no undo entry behind for them to recover it.
- A verified caret anchor — insert, then read back what landed and where — is a prerequisite that gates the feature. It is not a follow-up.
- Do not add `enigo`, `rdev`, or a CGEventTap. Synthesizing keystrokes gives no read-back, so it cannot satisfy the anchor requirement, and it needs a blanket Accessibility grant that turns every keystroke the user types into something the app can see.
